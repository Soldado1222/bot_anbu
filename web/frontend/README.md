# Dashboard Bot Discord - Frontend

Frontend React pour le dashboard de gestion du bot Discord.

## Configuration

Variables d'environnement requises dans Netlify :
- `VITE_API_URL` : URL du backend (https://bot-anbu.onrender.com)

## Déploiement

Le site est automatiquement déployé sur Netlify à chaque push sur la branche main.

URL de production : https://botanbu.netlify.app
